If you're distributing a script or tool that uses the Hardcover API, you can hand your
users a link straight to the [New API Key](https://hardcover.app/account/api/keys/new)
form with the scopes your app needs already checked. They just review, name the key,
and create it -- no hunting through the scope list themselves.

Pick a preset or check individual scopes below, then copy the generated link.

<ScopeLinkBuilder />

<Aside>
    The link only pre-fills the form -- the person creating the key can still add or
    remove scopes before submitting. Don't rely on it to enforce what a token ends up
    with; the [Actions & Scopes reference](/api/graphql/actions) documents what each
    scope actually grants access to.
</Aside>

## Building the link yourself

The scope picker above just sets a query string on the New API Key URL, so you can
also build it by hand -- useful if you want to generate it dynamically (e.g. from a
list of scopes your app already knows it needs):

```
https://hardcover.app/account/api/keys/new?scope=read:library%20write:library%20read:me:content
```

- `scope` is a space-separated (`%20` or `+`) list of scope names.
- Unknown scopes are silently dropped rather than rejected, so a stale link from an
  older version of your app will still open the form instead of erroring out.

`hc.search.books(query, options?)`

Searches books. The query goes to the API unchanged.

**Scopes:** `read:catalog`

| Parameter | Type | Required | Notes |
|---|---|---|---|
| `query` | string | yes | Query |
| `options` | object |  | Only the fields you set are sent. |

| `options.fields` | string[] |  | Index fields, e.g. title and author_names |
| `options.weights` | number[] |  | One per field |
| `options.typos` | number[] |  | One per field |
| `options.sort` | string |  | e.g. users_count:desc |

## Install

`@hardcover/sdk` is published on npm. It runs in Node 22.12+, browsers, Deno,
Bun and React Native, and has no dependencies.

## Get a token

Create a [personal access token](/api/getting-started/) with the scopes your
app needs. Each method's page lists the scopes it uses. Keep tokens out of
source control and out of browser bundles; apps that act for other people sign
them in with [OAuth](#signing-people-in) instead.

## Make a call

```ts
import { HardcoverClient, UserBookStatus } from "@hardcover/sdk";

const hc = new HardcoverClient({
  token: process.env.HARDCOVER_TOKEN,
  userAgent: "my-app/1.0",
});

const me = await hc.me.get();
const reading = await hc.library.list({ status: UserBookStatus.CurrentlyReading });
```

`userAgent` names your app in the API's logs, so problems can be traced back to
it. Try the same call with your own token:

## Signing people in

`@hardcover/sdk/oauth` signs people in with [OAuth](/api/oauth/) and keeps
their tokens working: it refreshes them before they expire, never spends a
refresh token twice, stores each new pair before using it, and tells you once
when the person needs to sign in again. You decide where tokens are stored.

```ts
import { HardcoverClient } from "@hardcover/sdk";
import { OAuthSession, secureStore } from "@hardcover/sdk/oauth";

const session = new OAuthSession({
  clientId: "your-client-id",
  redirectUri: "yourapp://oauth/callback",
  store: secureStore(SecureStore, "hardcover-tokens"), // Keychain / Keystore
  onSignedOut: () => showSignIn(),
});
const hc = new HardcoverClient({ auth: session });

const attempt = session.authorize({ scopes: ["read:me:content", "read:library"] });
// Open attempt.url in a browser, then hand the redirect back:
await session.completeAuthorization(redirectUrl, attempt);
```

TVs and command-line tools use `session.signInWithDevice(...)`, which shows a
short code to enter at hardcover.app/link.

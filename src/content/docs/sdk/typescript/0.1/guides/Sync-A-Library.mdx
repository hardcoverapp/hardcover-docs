An offline-first app keeps its own copy of the reader's library. Instead of fetching everything each time,
`library.changes` returns what changed since a cursor from the last sync.

## How it works

- **The first sync** starts with no cursor and returns the whole library, a page at a time.
- **Each page** comes with a new cursor. Save the entries and the cursor together, and keep going while `hasMore`.
- **Upsert by id.** A sync may send an entry you already have; replace it.
- **Removals** don't show up as changes, because the API deletes entries outright. Once per sync, pass the ids you
  hold as `knownIds`, and the reply lists the ones that are gone in `removedIds`.

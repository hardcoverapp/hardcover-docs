`@hardcover/sdk` is the official TypeScript client for the Hardcover API. It
runs in Node 22.12+, browsers, Deno, Bun and React Native, with no
dependencies, and handles what every app would otherwise repeat: signing users
in and keeping their tokens fresh, rate limits, retries, and typed results and
errors.

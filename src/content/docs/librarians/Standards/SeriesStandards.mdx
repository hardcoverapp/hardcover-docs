*This page covers standards for naming and organizing series, including duplicate names, adaptations, and publisher collection edge cases.*

## Duplicate Series Names
For multiple series with the same name, adjust the additional series as follows:
  - Append `-AuthorName` to the slug
  - Add missing series ID

If the duplicate series has multiple authors, the author of the first book is assigned as the series author and used for the slug disambiguation.

We used to recommend adding (Author Name) as a disambiguation to series names. This recommendation has been removed because the system automatically creates unique series slugs using the series name and author name, while keeping the series name itself undisambiguated. You can still use the author name as a disambiguation for comics or other specific scenarios where it is necessary. 

The Series ID field can save multiple IDs, so always check the original series to make sure the duplicate's ID has been removed and isn't still listed there.

When a series has been adapted into a different format (e.g., a manga that was novelized), we create a separate series for the adaptation:
  - The source format retains the series name (e.g., `The Summer Hikaru Died`)
  - For the adaptation, append `(Format)` to the series name (e.g., `The Summer Hikaru Died (Light Novel)`
  - For the adaptation, append `-format` to the slug (e.g., `the-summer-hikaru-died-lightnovel`)


## Publisher Collections (E.g., Penguin Little Black Classics)
For publisher or other collections where only a specific edition of a book is part of the series, a Hardcover series should not be created. The book may be instead added to a list.
